# No Dull Moments

A single-page website with ten small things to do when you're bored:

| Key | Channel     | What it is                                   |
|-----|-------------|----------------------------------------------|
| 1   | Reflex      | Reaction-time test                           |
| 2   | Pop         | 20-second aim game                           |
| 3   | Echo        | Memory game with a sequence that keeps growing |
| 4   | Noodle      | Snake                                        |
| 5   | Type Rush   | Typing-speed sprint                          |
| 6   | Kaleido     | Drawing with mirror symmetry                 |
| 7   | Dares       | Small real-world challenges                  |
| 8   | Pick One    | Would-you-rather questions                   |
| 9   | Rabbit Hole | True facts, with links to Wikipedia          |
| 0   | Riddles     | Classic riddles                              |

A **boredom meter** at the top fills up while you're idle. When it reaches
100%, the page switches you to a different channel. You can turn this off
with the toggle. Press `N` (or the Shuffle button) to jump to a random channel.
Your best scores are saved in your browser's `localStorage`.

To run it, open `index.html` in any modern browser. There's no build step and
nothing to install.
